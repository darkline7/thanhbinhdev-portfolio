# ThanhBinhDev — Creative Developer Portfolio

🚀 A stunning portfolio website built with modern web technologies.

## Tech Stack
- **Three.js** — 3D particle sphere animation background
- **GSAP** + **ScrollTrigger** — Smooth scroll animations, text reveals, parallax
- **Vanilla JavaScript** — No framework overhead, pure performance
- **CSS3** — Custom properties, glassmorphism, fluid typography

## Features
- 🎨 3D Particle System (Three.js WebGL)
- ✨ GSAP ScrollTrigger animations
- 🖱️ Custom cursor with magnetic buttons
- 📱 Fully responsive design
- ⚡ Preloader with text scramble effect
- 🎯 Tilt effect on skill cards
- 🌊 Infinite marquee ticker
- 📬 Contact form with animations

## Run Locally
```bash
npm start
# → http://localhost:3000
```

## Deploy on VPS
```bash
git clone <repo-url> /var/www/thanhbinhdev
cd /var/www/thanhbinhdev
npm start
```
